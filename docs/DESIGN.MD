# Design System

## Overall Direction
- Similar look and feel to the Jeopardy game show board
- Desktop-first
- Prioritize functional UI over decorative design

## Layout
- Persistent bottom row that shows the players and their scores

## Style
- Minimal

## Design Process

The design will evolve as features are implemented

When creating a new UI:
1. Follow established patterns from the existing application
2. Use reasonable modern UI defaults where no preference is specified
3. Do not invent a new visual pattern if an existing one works

## Color Scheme
Game creation and invitation screens are black and white. Primary buttons, including Join, Submit, and Continue, are Jeopardy blue. Secondary buttons stay white with a black border.

The game screen background is white. The board, including played and missing squares, and the score row use classic Jeopardy blue. Category titles are shorter than the clue squares. The round title and invitation code share the top row, with the code on the right, beside a door icon for leaving the game. Point changes sit beside the score. After the answer is shown, each submitted answer appears in a bubble above that player's place on the score bar. Players are spaced evenly, and each bubble stays within that player's share of the bar. The player choosing the next clue is marked with a yellow star to the right of their name. The question and answer switch is a short grey highlight, not a filled button.
